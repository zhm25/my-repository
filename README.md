# 能源前线 · Energy Frontier

一个不依赖服务器、不需要安装依赖的中文网页策略游戏原型。双方通过能源据点与管道发展，工程队施工，最多三支战斗群在地图上实时交战。攻陷敌方大本营获胜。

## 一、打开游戏（推荐）

### 方法 A：单文件离线版

1. 将 `能源前线-离线版.html` 下载到自己的电脑。
2. 双击该文件，或右键 → 打开方式 → Chrome、Edge 或 Firefox。
3. 页面弹出“部署你的能源前线”。
4. 选择“玩家对电脑”或“电脑对电脑”，保留默认地图种子 `2026`，点击“开始部署”。

这个 HTML 已包含所有样式与程序，不需要互联网、Python、Node.js 或账号。不要将代码复制到文字处理软件；保存时保留 `.html` 扩展名。

### 方法 B：源文件版

1. 下载并解压 `能源前线-游戏包.zip`。
2. 在解压后的文件夹中双击 `index.html`。
3. 必须让 `index.html`、`style.css`、`game.js`、`ui.js` 保持在同一个文件夹。
4. 也可以打开包内的 `能源前线-离线版.html`，它可以单独移动使用。

当前云工作区的文件不会自动出现在你的电脑上。先使用工作区文件界面的下载功能下载 HTML 或 ZIP，然后在本机打开。不能只把 `/workspace/...` 路径粘贴进本机浏览器。

### 方法 C：本地服务器（可选）

只有浏览器或组织策略限制本地文件时才需要。安装 Python 3 后，在游戏文件夹打开终端：

```bash
python -m http.server 8000
```

macOS / Linux 如果 `python` 不存在，改为 `python3`。然后在本机浏览器地址栏输入 `http://localhost:8000`。终端按 Ctrl+C 关闭服务器。这个地址仅指向你自己的电脑，不是公开网站。

## 二、第一局怎么操作

你控制蓝方，从左侧大本营出发；红方由电脑控制。

1. **先暂停。** 点击地图上方“暂停”，或按空格。暂停时可以查看状态和下令。
2. **认识图标。** 六边形是大本营，方框加号是工程队，三角箭头是战斗群，菱形是分据点，圆圈箭头是导弹基地。
3. **增加部队。** 左键选中大本营，在右侧点击“补充战斗群 · 130”。最多三支战斗群、两支工程队。如果单位重叠，反复左键同一格可轮换选择。
4. **探索扩张位置。** 选工程队，右键点击大本营上方的位置。例如默认种子中坐标 `(1,5)` 可达，且离大本营 `(1,11)` 恰好六格。鼠标移动到地图上时，下方显示坐标。
5. **恢复时间，等待工程队到达。** 暂停状态下部队不会执行移动或施工。到达后可以再暂停规划。
6. **建设分据点。** 选工程队，保留“建造建筑时自动规划连接管道”的勾选，点击“分据点”，再点击 `(1,5)`。工程队会先返回最近能源节点，沿路线铺管，再持续建设据点。
7. **观察能源。** 工程队仅自带 60 能源。据点需要 240，所以离网施工只会进行一部分；连接管道后才能持续补能并完成。黄色条表示施工进度。
8. **建立防御。** 选工程队，点击“导弹基地”，再选一块空地。初期可放在大本营或新据点附近，勾选自动接管。
9. **推进。** 选战斗群，点击“进攻移动”（或按 A），再点击目的地。部队沿途遇敌停下自动开火。右键敌人则指定攻击；右键空地是普通移动，不会为自动交战停下。
10. **补给与成长。** 生命值低或能源不足时右键撤到己方能源节点旁。三格内可补能；节点库存足够时可以升级或修复部队。

默认种子只是便于第一次操作，并非特别降低难度的教程关卡。电脑会同时扩张和进攻，可以多用暂停。

## 三、操作速查

| 操作 | 效果 |
| --- | --- |
| 左键 | 选择单位 / 建筑；同格多单位可重复点击切换 |

| 战斗群右键敌人或废墟 | 指定攻击；废墟也可彻底清除 |

## 四、手动管道与自动规划

### 手动铺管

1. 选择工程队，点击“铺设管道”。
2. 左键点起点，再点终点。
3. 程序会沿可通行格生成一段最短路线，避开山地和水域。
4. 工程队依次前往并铺设，每格消耗 4 能源。已有己方管道不会重复收费。
5. 如需多个转折点，第一次点击终点时按住 Shift，随后继续按住 Shift 点击下一终点；最后不按 Shift 点击终点，结束追加。

“手动”指由你指定路线端点和转折点；各段之间使用格子寻路，不需要逐格点击。新规划默认替换该工程队原有队列，Shift 则追加。已经铺好的管道和已经产生的建筑施工进度不会被删除。

先从己方节点附近开始铺管。若从远离节点的位置施工，工程队最多能铺 15 格，随后可能耗尽能源。可以把它移回供能节点补充，再修通线路。

### 自动接管

勾选自动规划后，下达建筑命令会先安排从最近可达己方能源节点到目标的管道路线，再安排建筑施工。取消勾选后仅安排建筑施工，适合已经手工规划好管网的场景。

工程队会等待缺失的能源。管线被打断时，玩家需要修复缺口、重新下达接管路线或让其他工程队接手；电脑有断供后重新连接的行为。遇到敌方建筑、管道或不合法间距时，工地可能取消，原因显示在战地通讯里。

## 五、能源与建设规则

- 地图 32×22，共 704 格。默认山地 **140 格**、水域 **36 格**、富能源区 **18 格**，其余为平原。山地增加、资源区更稀缺，两侧也参与地形生成。
- 开始前可选择 **左右镜像 / 中心对称（旋转 180°）/ 不对称**，分别输入山地（0～280）、水域（0～140）、资源区（0～100）的格数。
- 对称地图成对放置地形，设置使用偶数格。出生安全区和连通走廊不放障碍；极端组合超过可分配空间时，按山地、水域、资源区的顺序分配，开局提示显示实际数量。
- 大本营移至横坐标 **1 / 30**。默认纵坐标为 11；中心对称时红方纵坐标为 10。保留纵向补给走廊和横向通路，保证双方可以抵达对方起点。
- 平原可建造；山地和水域不可通行、不可建设；富能源区提高分据点产量。
- 大本营、分据点之间的直线距离至少为 6 格，双方据点和废墟都计入。
- 每方只有一座初始大本营，不能新建、重建。它被摧毁后立即判负。
- 能源储存在具体单位内，不是全图通用的金钱。总览中的库存是已完工能源节点的库存之和；招募用的是大本营本地库存。
- 管道按上下左右相邻格连接。建筑与同格或相邻格管道连接。
- 完工的大本营 / 分据点是能源源头，能够独立发电。断网的分据点仍能给自己的局部网络供能。
- 同一网络总输送预算为 **32 能源/秒**，单个接收单位最多 **12/秒**。初版按整个连通网络计算容量，不逐条管道模拟流量。
- 工程队和战斗群可以在完工能源节点 **3 格**内补能，或在有效管道约 **1 格**内接入供能。工程队有补能优先权。
- 亮色线路表示连通了能源源头；不保证源头当前有足够库存。节点没钱时仍可能补给不足。
- 管道本身不储能、不耗能；建筑和移动单位有独立库存。
- 施工速度最多 12 能源/秒，供应不足会减慢或暂停；施工中的建筑不生产、不攻击。
- 已完工建筑即便断供，也会先使用本地库存。导弹基地库存不足 5 时不能发射。

### 初始数值

| 对象 | 生命 | 防御 | 储能上限 | 产出/秒 | 基础消耗/秒 | 建造/招募费用 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 大本营 | 800 | 35 | 500 | 9 | 0.5 | 不可建造 |
| 分据点 | 320 | 20 | 220 | 5；富能源区 8 | 0.4 | 240 |
| 导弹基地 | 260 | 15 | 100 | 0 | 0.7 | 180 |
| 战斗群 | 210 | 25 | 100 | 0 | 0.12 | 130 |
| 工程队 | 90 | 5 | 60 | 0 | 0 | 70 |
| 管道 | 55 | 0 | 0 | 0 | 0 | 每格 4 |

初始大本营储能 350；初始部队满储能。大本营还会以 14 攻击力、3.5 格射程、1.4 秒间隔自动防守，每次射击消耗 2 能源。

## 六、实时战斗

- 战斗群：攻击力 23，射程 3.3 格，射击间隔 1.3 秒，每次消耗 2 能源。
- 导弹基地：攻击力 29，射程 5 格，射击间隔 2.5 秒，每次消耗 5 能源。
- 伤害 = 攻击力 × `100 / (100 + 防御力)`，高防御不会完全免伤。
- 山地阻挡普通直射，导弹可越过山地，但都只能攻击当前己方可见的目标。
- 部队基础移动速度 1.65 格/秒，移动每格额外消耗 0.7 能源。能源低于 1 时降至 45% 速度，射击能源不足时不能开火。
- 自动选择射程内的敌方战斗群、导弹基地和大本营，优先战斗群；破坏分据点、工程队、管道和废墟需指定目标。电脑也会主动攻击可见的补给设施。
- 驻守不主动追击。普通移动会继续行进，并可向射程内敌人开火；进攻移动遇敌停下交战。
- 战斗群最高 **20 级**。从当前等级 L 升级的费用为 `90 × 1.4^(L−1)`，四舍五入到十位：第一次 90，后期单级费用可达数万能源。
- 升到等级 N 时：生命上限增加 `40 + 4 × (N−2)`，攻击增加 `6 + 2 × floor((N−2)/3)`，防御增加 8，储能增加 15；恢复本次增加的生命值。
- 每级射程增加 **0.06 格**，移速增加 **0.018 格/秒**。20 级时射程 4.44 格、基础移速约 1.99 格/秒。
- 在完工能源节点三格内启动升级，先从该节点所在连通网络的能源源头共同支付库存；不足部分作为升级项目，继续分期投入。每秒投入最多 24，且受网络每秒总输送预算 32 限制，单位日常补给优先。
- 无需让单个节点存下全部费用。只要持续产能和接管，就能完成昂贵升级；离开节点或断供会暂停，已投入部分保留。部队被消灭时其升级投入也会损失。
- 界面显示当前移速、精确射程、下一次升级费用或正在进行的投入进度。电脑同样可升级至 20 级，并优先培养存活的高等级部队。
- 修复花费附近节点 40 能源，恢复最多 90 生命。升级和修复都要求位于完工能源节点三格内；修复仍使用该节点的本地库存。
- 初版允许单位重叠，不模拟士兵编队、碰撞、朝向或友军火力。

## 七、废墟

普通建筑被摧毁后留下 100 生命的废墟，保留建筑类型并停止运作。

- 任一方工程队都可以通过“重建废墟”工具开始重建，费用为原造价的 60%。
- 重建仍需持续供能。据点为 144 能源，导弹基地为 108。
- 重建施工开始时工地归施工方，完工前不生产、不攻击；敌方仍能攻击施工中的建筑。
- 战斗群右键废墟可将其彻底清除。
- 据点废墟继续占用六格间距，清除后释放。
- 大本营毁灭后战局已经结束，不会通过废墟复活。

## 八、迷雾与电脑观战

人机模式锁定蓝方视角：未探索区隐藏地形；探索过但当前不可见的区域显示暗色地形和建筑最后已知位置，隐藏敌方移动单位。自己的存活单位始终显示。重建和攻击必须符合相应视野规则。

视野半径：战斗群 6 格，工程队 4 格，已完工建筑 5 格。初版视野是圆形范围，不模拟地形遮挡侦察；山地仍会挡住直射火力。

电脑对战模式：

1. 点击“新战局”，选择“电脑对电脑”。
2. 默认全图观察，可切换蓝方 / 红方视角。
3. 选择 2×、4× 或 8× 加速。
4. 暂停并点击单步，每次观察一秒变化。
5. 总览显示双方经济及“补给 / 扩张”“集中进攻”“紧急回防”等当前战略状态；战地通讯显示建造、损失和胜负事件。

观察视角不改变电脑拥有的信息。电脑遵守单位上限、能源库存、建造费用、目标视野与同一套战斗规则，没有额外资源。静态地图用于寻路，对方出生区域作为探索方向；不可见敌军位置不会被用来瞄准。

电脑会招募、扩建据点、连接管道、建设导弹基地、重建废墟、缺能时重接施工路线；军队根据补给和伤势撤退、修复、升级，发现近处威胁时回防。它是规则式初版 AI，尚无复杂包抄和完整长远经济规划。

地图种子与地图设置相同且不人为介入时，模拟过程可复现。新的高级部队成长用于强化后期经济优势，但仍没有强制限时判胜，不能保证所有地图都不会僵持。依照本次要求，本轮修改没有运行模拟测试或浏览器测试，旧版的测试结果和对局时长不代表新版。

## 九、开发与验证

文件结构：

```text
index.html                 页面结构
style.css                  界面样式
game.js                   模拟引擎与电脑逻辑
ui.js                      绘制、交互、视角和速度
能源前线-离线版.html        生成的单文件发行版
build.py                   重新生成离线版及 ZIP
tests/simulation.test.js   无第三方依赖的模拟测试
tests/browser-smoke.js     可选 Playwright 浏览器测试
```

模拟测试需要 Node.js 18 或更新版本：

```bash
node --test tests/simulation.test.js
```

浏览器测试需额外安装 Playwright 和 Chromium，并在另一个终端从项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，再执行：

```bash
node tests/browser-smoke.js
```

可用 `CHROMIUM_PATH` 指定浏览器可执行文件，用 `GAME_URL` 指定本地测试地址。普通游玩不需要这些工具。

修改源文件后，重新生成离线版和 ZIP：

```bash
python3 build.py
```

测试覆盖地图可复现性、离网施工、持续供能施工、断管、废墟重建与清除、招募上限、升级、射线和迷雾、战斗伤害、终局冻结及完整电脑对战。浏览器测试覆盖实际选择、招募、移动、建设、手动铺管、单步、弹窗、观战和终局界面。
